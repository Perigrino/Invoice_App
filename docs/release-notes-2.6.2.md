## InvoiceFlow 2.6.2

- Header spacing: the title, subtitle and the control under them now keep one
  rhythm on every screen — Invoices, Clients, Settings and both form sheets.
- Failed update checks now say what actually went wrong (for example a request
  that timed out) instead of only asking you to try again.
- No data or schema changes — your invoices, clients and profiles are untouched.
